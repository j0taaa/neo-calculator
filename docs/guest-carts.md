# Standalone carts

Signed-out users can create carts directly in NeoCalculator. The Local Carts panel replaces the account Projects panel; a first empty cart is ready automatically. These carts have no parent project and do not create database records or accounts. Signed-in users can open the same browser workspace through **Open local carts**, at `/cart`.

Cart controls include create, select, rename, duplicate, delete, product editing, filters, clipboard copy/cut/paste, queued configurations, JSON import/export and sharing. Existing account carts and project permissions are unchanged. Legacy text batches stay in the account workspace; standalone carts use the independent calculator's queued configurations. Browser storage commits before a save is acknowledged. Failed writes, corrupt storage, and another tab's intervening changes cannot silently overwrite the existing workspace. Corrupt stored data can be downloaded for recovery.

Guest saves and reloads replay selections through the browser's independent calculator engine. Persisted prices are never treated as authoritative. Browser and server pricing outputs share `independentProductBody`, including component quantities, payment details and price breakdowns. No Huawei requests, upstream UI or pricing proxy is introduced.

Import Cart and Import Project use the existing schema popup. JSON is checked by the public, stateless `/api/v1/cart/validate` endpoint against one published release before any local writes. This endpoint runs Neo's engine and does not write account data. Importing a project creates separate local carts; the project itself is not retained. Exports use the existing saved-cart JSON format, omit account/project metadata and IDs, and can be imported into an account project later. Original saved exports and agent-generated v2 documents remain supported when their configurations can be reconstructed.

**Share Cart** produces a compressed snapshot in the URL fragment, at `/cart#cart=v1.…`. The fragment is processed in the recipient's browser, rather than sent as a server resource identifier. Opening it validates configurations and current prices, creates fresh local IDs and preserves the recipient's other carts. Authenticated recipients also open the standalone workspace. Editing a copy does not update the sender's cart. The link is a self-contained copy, with no server-side revocation or live collaboration; account sharing retains its existing separate behavior.

The workspace is limited to 100 carts, 1,000 total products and 2 MB of serialized data. Share links are limited to 64,000 characters and decompression is bounded to 2 MB; larger carts should use JSON export. Clearing this site's browser data removes local carts. Export or share a copy before doing so. Signing in does not automatically upload local carts.
