Huawei calculator without Chromium

HTTP requests fetch Huawei’s sources and prices. Node executes the official JavaScript in a DOM emulator. This experiment discovers every calculator in the directory; unfamiliar widgets and incomplete quotes are rejected. It has no Chromium fallback.
